# Speculator

This subcategory contains pipelines in the **Speculator** group:

- [Speculator Data Only Pipeline](./data_only/README.md): Extract verifier hidden states using managed or external vLLM.
- [Speculator Offline Pipeline](./offline/README.md): Extract hidden states, train and evaluate the draft, register it, then serve it.
- [Speculator Online Pipeline](./online/README.md): Train, evaluate, register, and serve an Eagle3 speculative decoding model.
- [Speculator Train Only Pipeline](./train_only/README.md): Train, evaluate, register, and serve a draft model from pre-extracted hidden states.
